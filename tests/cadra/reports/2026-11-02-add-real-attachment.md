# Cadra 真实会话附件留存验收 · 2026-11-02

结论：附件留存与只读交接通过。用户实际上传图片并明确确认采用方案后，Cadra add 保存了图稿副本及确认结论；不继承原会话的独立执行者仅凭任务资料完成读图和摘要核对。不是模拟 PNG 或 unittest 替代实际调用。

## 环境与方法

- 实际安装副本：`~/.agents/skills/cadra`，Cadra 0.17.0／协议 0.12；对应源码提交 `e3b8a7434699257d3fe25b93ca15b76be410f9a4`。
- 临时项目位于 `/private/tmp/cadra-real-attachment-tjzyagww/project`。准备者 `/root/cadra_real_attachment_add` 与读取者 `/root/cadra_real_attachment_reader` 均使用 `fork_turns=none`。
- 真实输入为用户本轮重新上传的 PNG 及“我重新附上设计稿了，确认采用这个方案”的明确确认。用户未手工输入文件路径，宿主通过图片附件元数据提供临时文件入口。
- 准备者实际执行 add。读取者只取得项目与 Task 路径，按指令不读取原附件、原聊天、父会话或测试证据；从 Task 解析项目内保存副本并实际查看。此范围由交接指令约束，不声称使用了额外的操作系统访问隔离。
