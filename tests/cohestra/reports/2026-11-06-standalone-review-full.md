结论：本次 Cohestra 0.18.0 的验证矩阵全部通过，未发现需要修复的技能规则或兼容性缺陷。协议保持 0.8。

本轮覆盖规则独立审查、实际安装、508 项自动回归和 10 个新增行为场景。前轮的默认调用、工具受限、自审及复用 reviewer 复审证据仍适用，见[基础实测](2026-11-06-standalone-review.md)。本报告不将有限场景测试解释为所有环境和故障的穷尽证明。

## 规则与包检查

独立审查者 `/root/rule_audit` 只读核对当前差异及原始消费规则，未发现确定问题。范围包括派发授权、真实身份、干净上下文、唯一写入、停止边界、blocked、自审例外、Cadra/closeout 不递归派发和版本兼容性。完整记录保存在[原始证据](2026-11-06-standalone-review-full.json)。

- 包版本由 0.17.0 升为 0.18.0，符合默认执行流程变更的 MINOR 规则；完整本地历史非 shallow，无版本复用。
- Front Matter 字段、枚举和状态语义未变；协议继续为 0.8，Cadra 无须升级。
- 技能格式校验、包内链接/隐藏资源、独立副本、双语 README 一致性、完整 Git 历史版本检查及 `git diff --check` 通过。
- 全量入口 `python3 -B -m unittest discover -s tests -p 'test_*.py'`：508 项通过，无跳过。新增 3 项直接测试原子替换拒绝、竞争写入保留和解除故障后的真实文件发布；不模拟 agent 决策。

## 新增行为场景

| 场景 | 实际观察 |
|---|---|
| 自动选择 review | 主会话自动选择 review 并创建干净上下文 reviewer；发现夹具真实缺陷，发布 review 后停止，未执行 fix/validate |
| unattended | 使用 CLI 安装副本、新独立 reviewer；保留 unattended，未等待提问或降低门禁，完成审查和索引发布 |
| 固定候选不可取得 | git cat-file 实际退出 128；不改用 HEAD 或新快照，不派发无效审查；blocked/candidate_unavailable |
| 身份依据缺失 | 在明确缺作者审计的受控输入下不猜测作者分离，不退回自审；blocked/missing_input |
| 自审例外与既定门禁 | 按本次明确指令自审，记录非独立方式；既定独立验收门禁保留，不写 acceptance passed |
| 索引发布失败 | YAML 校验成功后独立调用 publish；实际原子替换产生 PermissionError；保留 handoff，回读旧索引并报告同步失败 |
| 同轮恢复 | 测试宿主解除故障后，仅恢复同一 review-01 的索引同步；重新校验、发布、回读通过；不新增轮次，不改 handoff 或重跑审查 |
| 竞争写入冲突 | 外部驱动在比较前实际追加竞争记录；发布停止，保留该记录及审查交付，不重试覆盖，报告索引同步失败 |
| 更换 reviewer | 按明确重审请求创建新 reviewer；12 项检查通过，新增 review-03；原 review-01/02 字节不变，未执行 fix/validate |
| closeout 兼容 | 独立 reviewer 不再委派；review 无 findings 后，主会话串行 validate 并复用有效证据；最终 completed / acceptance passed / next null / blocked false |

Closeout 审查索引首次 YAML 编码校验失败时没有发布；修正编码并收到完整校验成功后才发布。验收联合校验、发布及回读均成功。没有生成空 fix。

实际身份与来源包括主会话工具创建返回值、派发记录、执行者交付和回读观察。正常委派都使用 `fork_turns=none`。主验证会话另行解析各最终索引，核对固定候选、阶段/轮次、业务文件无改动、旧交付摘要、失败/恢复事件及竞争记录保留。身份自述未作为唯一证据。

## 证据与边界

[JSON 证据](2026-11-06-standalone-review-full.json)保存包摘要、差异、独立审查、实际 CLI 命令及输出、调用来源、原请求、交付正文、最终契约、发布事件和主验证断言。

- 身份缺口是明确声明的受控条件；未声称身份服务真实故障。竞争写入是驱动注入的实际文件变化，不是两个真实用户同时操作。
- 更换 reviewer 是明确要求，未模拟运行时丢失或强制终止。没有实测强制杀死子 agent 或重跑整套 Cadra 队列调度；Cadra 消费兼容由独立规则审查和现有完整回归覆盖。
- 安装实测限隔离项目作用域；未宣称验证真实用户作用域安装或宿主选择器自动发现。
- 验证未提交、推送、发布技能包，也未更新实际用户安装。此次新增内容仅为仓库测试与验证记录，不再升级技能包。
