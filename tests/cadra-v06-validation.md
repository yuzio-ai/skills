## 变更与范围

- 发行版 0.6.0、任务/Run 协议 0.6；Cohestra 契约仍为 0.8。

## 执行证据与限制

独立智能体明确加载本仓库 Cadra 与 Cohestra，在隔离临时 Git 项目执行；没有网络、提交或业务项目写入。临时 Python 辅助用于写入、快照、校验和记录已选动作，不安装进技能包；阶段判定与工作由智能体执行。归档保留原绝对路径及实际时间，哈希清单定位归档副本，不修改原交付来伪造便携路径。

中断是独立智能体额度限制导致，停在 code-02 handoff 写入后、README 校验发布前；不是人工注入。原 code-02 候选及测试完整，主会话接手后只修复索引发布并恢复原调用，再执行剩余阶段。两次 closed Run 查询为主会话只读核对，哈希不变；并非两次新的独立智能体调用。

首轮独立协议 reviewer 因同一额度限制未执行。当时完整的独立 resume/修订闭环缺第二个独立执行者证据；不得将主会话续验或模型测试标为该证据。当时已独立完成的范围是第一轮双任务执行，以及第二轮 add/ready/run/code。后续独立复核见下节。

系统 Python 缺 PyYAML，原生 skill-creator quick_validate.py 启动失败。没有安装依赖或修改验证器；改用 Ruby Psych 检查真实 YAML，并执行等价的技能元数据与未完成占位检查。该替代不标记为原生 quick_validate 通过。

未迁移旧协议、未更新本机安装副本、未提交、推送或发布。后续使用源仓库明确路径才能选到 v0.6。
