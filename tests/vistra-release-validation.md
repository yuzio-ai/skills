# Vistra 0.1.0 项目试用版

本页保留 0.1.0 时点记录。当前 0.1.1 检查见 [精简验证](vistra-simplification-validation.md)；旧 HTML 路径的历史验证不作为当前静态图片流程的通过证据。

本次按维护者决定先发布，再在实际项目中验证和迭代。发布范围为完整 `vistra/` 包、开发规格、中英文说明、包结构测试及本记录。历史实验日志、设计产物和原型夹具不随首版发布；历史结果不计为当前静态图片版本通过。

## 能力与边界

- 四模式：review、explore、compare、handoff；三领域：mobile、desktop、brand。
- 通过宿主已有图像能力直接生成或编辑静态图片；产物默认位于 `.yuzio/vistra/`。
- 不制作 HTML、交互原型、审阅网站或本地渲染执行器，不修改生产代码，不发布工程验收结论。
- Taste 定制方法、来源和许可证包含在包内；无 Taste 运行依赖，不安装 Vistra Tools。
- 与 Cohestra、Cadra、Relatra 使用可读交接约定；自动消费及目录迁移未完成。

## 项目试用待验证项

以下六项均未在本次发布中执行；按实际项目需要逐项积累证据。

| ID | 场景 | 观察重点 |
|---|---|---|
| S01 | 移动端两个方向，已有文案与截图 | 两张静态图片、实际查看、文案保真，不制作代码原型 |
| S02 | 桌面页宽屏与窄屏方案 | 共享图片预算；适配意图与真实响应布局验证分开 |
| S03 | 已有品牌应用，冻结 Logo 与文案 | 使用原素材作为参考或编辑输入；无法保留时明确缺口，不转为代码合成或母版制作 |
| S04 | 图像工具不可用，已有 A/B | 继续已有候选比较；新图缺口保留，不用 HTML 替代 |
| S05 | 请求静态方案与点击验证 | 图片按约定交付；点击验证交工程流程，不声称图中按钮可操作 |
| S06 | 采用准确图片版本并交接 | 沿用有效选择，保留图片引用与必要说明，参数和素材未知项明确 |
