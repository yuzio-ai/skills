# 报告写作

面向个人项目复盘。agent 负责判断与归纳，脚本负责完整明细和确定性统计。重点正文不是所有任务的压缩清单，任务数量、耗时或关键词不能自动代表价值或优先级。

## 正文

核实完整账本后，将带 Markdown 二级标题的结构化摘要写入现有 `summary` 字符串，按以下顺序组织。无内容栏目省略，不用“无”填满模板。

| 栏目 | 内容 |
|---|---|
| 本期概况 | 1–2 句说明主要进展和关键缺口 |
| 需你处理 | 有明确依据的决定、授权或人工操作；全部重要事项前置，不从 blocked 状态推断需要用户介入 |
| 主要成果 | 按项目和目标归纳，通常 3–5 项；说明实际变化、完成程度和关键限制 |
| 关键遗留 | 影响目标推进的阻碍、未完成事项和重要验证缺口 |
| 下一步 | 通常不超过 3 项，按优先级列出行动及原因；不执行原任务 |

数量是写作目标，不机械截断重要信息。同一信息不在多个栏目重复；成果后的限制已经说清时，关键遗留只补充其他阻碍或影响。实现、验证、验收和发布分别表述，例如“构建通过，尚未验证真机”；没有发布证据不写已上线。影响完成判断的限制必须紧跟对应成果，不能只留在明细。没有明确目标或计划基线时，不判断延期或进度符合预期。建议须有相关任务证据，不从成本推断因果或效率改善。

正文成果链接到 details.md 中对应任务的锚点。合并多个目标时提供各目标链接。锚点由脚本 `task_anchor(task)` 返回，为 `task-` 加上 `digest([id, revision])` 的前 16 个字符；同 id/revision 的标题、排序和周期变化不改变锚点。可导入实际包脚本调用该函数或查看生成明细，不猜锚点。

`summary` 只保存本期重点摘要，不复制统计表、证据编号、采集诊断或资源行。脚本将摘要原样写入正文，再附分项覆盖说明及一行已观测累计执行时间、token、其中缓存输入与明细入口。未知字段分别写未知；覆盖不足的数值标为部分观测值。时间取整时标“约”，token 使用万、亿等短单位，舍入时也标“约”；明细保留准确时分秒、原始秒数及千位分隔的 token 数值，不换算费用。空白摘要触发“尚未整理重点摘要”的概览回退，不由脚本选择重点；旧的普通文本摘要仍可生成，执行者应按当前用途重新整理。

报告头部分别标明统计周期、实际截止、阶段性状态和本期已发现活动的首末日期。活动日期来自未排除轮次的本期活动时间与明确执行区间，不使用文件修改时间，不代表首末之间连续完整覆盖。第一条已发现活动晚于周期起点时，明确更早的本期工作情况未知；空记录标明本期未发现可归属记录，活动日期未知。任务归属、时间和总 token 的已知轮数分别说明，采集提示不能一概写成任务归属缺失；完整 warnings 留在明细和 JSON。

## 当前结论与遗留

明细依次展示当前结论、当前限制、未闭合行动、历史事件与证据。agent 根据截止前已核读证据整理 `outcome`、`limitations` 和 `next_step`；脚本不从关键词推断发布、验收或后续行动完成。已经推送的目标应在当前结论说明已推送，尚未同步安装、尚未运行验证等独立缺口继续保留。已解决的“未提交”等限制退出当前限制，旧事件、原证据和旧报告保持原样。

按实际行动人工合并语义重复遗留，每项行动只保留一个主要归属目标的 `next_step`。已有证据证明完成的待办清空；仅指向另一目标的说明不作为未闭合行动。不同目标承担不同验证时分别保留。不得为去重合并任务 ID、改修订号或重写交付日期；取消的任务不重新列为待办。对账本的更正仍通过新报告版本保存，脚本不做模糊匹配或自动删除。

## 周期归纳

- 日报：当日实际推进、当前阻碍和次日重点；同一目标的多次修改合并描述。
- 周报：按本周目标或工作主题归纳阶段进展、未闭合事项和下周重点，不逐日拼接日报。
- 月报：按项目阶段目标归纳成果、主要差距和下月重点；方向或投入调整仅在有依据时建议。
- 季报、年报、自定义周期沿用相同正文结构，不自动增加分析能力。

历史成果不重复算作本期成果；无本期活动的未闭合事项仍完整列入明细，重要者进入正文。深度模式的关键判断进入摘要，趋势表、返工、人工介入等统计留在明细；长周期本身不触发深度模式。相同账本在不同周期应按实际窗口重算，不把全部历史成果带入每期。

## 交付核对

生成前核对摘要与任务状态、事件和限制一致，链接对应本期明细中的准确 id/revision。生成后查看正文和明细，确认需你处理事项前置、关键限制未省略、下一步有依据，且完整任务和未闭合行动未因精简而丢失。语义核对由 agent 完成，脚本不把有摘要等同于结论正确。

正文、明细和 JSON 由同一次 report 调用生成；更新摘要也通过账本与新报告版本，不编辑已生成文件。正式交付遵循 [存储约定](storage.md)，连同明细保存并核对相对链接和正式来源。
