# Cadra 审查修复

已修复[完整审查](../cadra-full-review-20261026/README.md)的 F1、F2，并补齐 G1 的当前模型回归与 Run 内结构化轮次校验。

## 修改

- **F1**：只有未执行的 queued 项可以转为 skipped。skipped 不得包含调用、预算消费、已消费授权或交付 checkpoint；非法历史记录也会被拒绝，不能放行新 Run。failed 保留未闭合调用的恢复方式不变。
- **F2**：retry_stage 必须为 null 或本次阶段。guard 根据 before 核对整改和失败重试费用；后续 before 必须存在，并与已保存的上一完整交付一致。四轮整改少收费、非法重试阶段及失败重试少收费均被拒绝。首次 fix、acceptance_failed 整改和有冻结修订及消费授权依据的首轮修订重启仍可合法计费。
- **G1**：复审/复验按本阶段已有最高轮次核对。Run 内保存的旧 review/validate 交付不能作为新一轮结果闭合调用；当前测试模型支持传入经来源核实的历史契约，覆盖跨阶段和跨 Run 的轮次比较。跨 Run、尚未登记的正式 handoff、候选、同步及实际派发来源仍由调用者核实。

包内只修改 run_guard.py、contract.md、executor.md 与 Run 模板；[本次包修改差异](package-fixes.patch)以审查时的逐文件摘要为基线，不混入此前未提交的流程统一修改。新增 test_guard_safety.py，补齐当前模型，并更新原有夹具的 before/交付证据及场景说明。

Cadra 仍为 **0.10.0 / 协议 0.10**。0.10.0 尚未进入 Git 历史，本次复用同一未提交发行版；修复恢复已有状态、预算与新交付语义，没有新增协议字段或枚举。Cohestra 包未因本次修复修改。
