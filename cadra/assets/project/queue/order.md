# 队列清单

列定义（各入口按此读写，不改列序）：

| 列 | 含义 |
|---|---|
| 序号 | 两位起、不截断；入队顺序，重排不改历史行 |
| slug | Task 标识 |
| priority | 入队时的优先级 |
| 依赖摘要 | 入队时依赖及其状态快照 |
| 入队时间 | 实际时间及时区 |
| 消费 run-id | 本次入队所属 Run，建立入队行时即记录；与 slug 共同定位该行 |
| 入队操作编号 | `enq-<run-id>-<NN>`；一次入队的唯一编号。行存在且带该编号即入队写入完成；补齐队列行按此编号去重，不重复追加 |
| 出队操作编号与结论 | `deq-<run-id>-<NN>` + Task 终态，或调度回退「回 ready（本轮 skipped，原因）」+ 时间；为空表示尚未出队 |

本文件由首次入队按本模板创建（最小初始化已带表头）；不存在表示尚无队列记录，不算缺口。入队与出队的操作编号、三步写入顺序与幂等补齐范围见技能包公共流程第 4 节第 7–9 条；出队语义见第 2、4 节。

恢复进入新 Run 时为同 slug 追加新行；定义修订后的重启（公共流程第 6.3 节）同样追加新行，并在出队结论中注明 `rev-<N>`、原 Run 与原终态。写入与回写只针对该 `enq-` 编号（与 slug 共同定位）的行：不覆盖旧 Run 行、不重写已有结论、不重复追加同一编号的行。

**旧版清单升级**：表头为七列（缺「入队操作编号」与「出队操作编号与结论」）时，**不修改任何历史行**，在文件末尾追加一个完整的八列表块（含表头与分隔行）；此后新行只写入新表块，旧表块原样保留。缺新列时直接向旧表块追加八列行会造成列含义错位，禁止。

- **读取**：按表头分别解析各表块并合并为一个视图；旧表块缺失的新列写 unknown，不回填、不重排、不迁移历史行。
- **定位**：新表块的行以 `enq-<run-id>-<NN>` 定位并以消费 run-id + slug 复核；旧表块或缺少该列的行只用消费 run-id + slug 定位。
- **写入**：入队新行只追加到新表块；**出队回写按行就地写入该行自己的结论列**——新表块的行写「出队操作编号与结论」（含 `deq-` 编号），旧表块的行写它既有的「出队结论与时间」单元格。旧表块的冻结范围是**列结构与已有结论的行**：不迁移、不回填新列、不改列序、不重排、不改写已出队的行；唯一允许的写入是给**仍未出队**的行补写它本来就有的那个结论单元格，且只写一次。表块顺序即追加顺序，读取不依赖表块位置。
- **完成判据**：合并视图中，某行只要**自身的结论列非空**即为已出队——新表块看「出队操作编号与结论」，旧表块看「出队结论与时间」；旧行不因缺少 `deq-` 编号被判为未出队。判定某 Run 是否还有未出队任务时按本视图，不只看是否存在新表块。
