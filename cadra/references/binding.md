# 既有交付身份绑定

add 发现同名 Cohestra 索引或正式 handoff 时读取本页。只检查该任务目录的交付存在性、README 索引的 contract/task、目标摘要与用户绑定依据；不默认通读各阶段 handoff。

- contract 必须为当前支持的 0.8，task 必须等于 slug，目标须与 requirement 对应。已有上下文明确确认且仍适用于当前身份与目标时沿用；未确认或主题不对应时停止绑定，请用户选择接续或更换 slug，不静默收养。
- 有正式 handoff 却缺 README，或身份字段缺失、无法解析、版本不支持时停止绑定，报告准确路径；不补造索引或将已有交付当作全新任务。两者均无时仍须结合 Run 归属核对，不能仅凭文件不存在推定没有历史。
- 身份与确认齐备后，记录主题、来源及确认依据。其余控制字段、候选适用性、完整契约与合法首动作由 ready 的起点项检查，并由 run/append 再核对；add 不沿用完成结论。已经发现的契约缺口写入任务，身份核对不记为 Gate 通过，不宣称可执行。

上述身份规则同时用于后续接续。完整执行准入见 [契约前置检查](contract.md#前置检查与首个动作)；add 不因此加载终态映射、预算或执行角色规则。
