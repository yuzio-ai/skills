# 协议边界与本地切换

本包写入、准入与执行仅接受 Cadra Task/Run 协议 `0.12`，继续消费 Cohestra 契约 `0.8`。仅 [list](list.md) 支持 `0.10`、`0.11` 原记录的只读查询：0.10 保留原串行状态；0.11 保留原固定小组、资源等待及完成语义，不套用 0.12 收尾门槛。两者均不写回、不补字段、不报告或派发。其余入口（含 add/ready/run/append/resume/report）拒绝旧协议；缺版本、0.9 及更早、未知版本也拒绝。不能只改协议号伪装升级。

list 可展示当前容器根目录独立的 0.10/0.11/0.12 记录，保留源协议、旧记录只读标记与已有调度信息。Run 和定义快照须同协议；跨协议来源链及依赖不拼接为执行依据，异常标 unknown。旧 Run 的 running/interrupted 不证明活性或可接管，交回原环境；查询不迁移、不递归扫描归档。

本机资料切换在技能运行之外完成：先由原环境闭合全部未完成 Run，备份容器及安装副本，再原样归档已结束 Run、报告和已完成 Task。归档不参与扫描、来源链、解析或准入，不回填新收尾或改写旧结论。

仅仍需执行的 Task 进入新容器，保留目标、AC、slug 和 Cohestra 绑定。重新核对既有交付，记录归档来源与原修订；已执行待办建立新修订，旧 Gate 失效并重新 ready。原失败原因未解除不能准入，不借切换重跑完成任务。

新容器从新协议建立来源链，不引用归档 Run 为 previous_run／revision_base.run；切换来源只作正文审计引用。接续已有 Cohestra 交付仍按身份、修订和恢复核对，不凭没有新 Run 认定从未执行。

存在未完成 Run、未闭合调用、状态矛盾或未知执行时保留原环境；不为升级接管、停掉或篡改执行。无运行批次时同步切换安装副本与资料，重新加载技能。没有自动迁移实现；历史维护工具不是本协议迁移器或技能运行依赖。
