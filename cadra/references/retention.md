# 留存与归档清理

本页只约束过程资料的存储维护，不新增技能入口、工程阶段或 Task/Run 字段，不改变协议、预算、执行归属与历史结论。Cohestra 管理的工程交付只引用，不在 Cadra 清理范围内删除或重写。

## 日常留存

- 提案只承载一次待发布更新。成功发布并回读确认后，调用者移除本次拥有、已消费且无引用、无恢复用途的提案；不要为每次状态保存永久积累一份完整 Run 副本。存在摘要冲突、写入或回读失败、提交结果不明时保留现场；中断遗留先核实原操作，不因文件名像临时文件就删除。
- 不覆盖其他调用者或并发 append/report 的提案。运行期间仅处理本次写入的临时文件，不扫描清扫整个 Run；被引用的提案按证据保留。锁文件不得删除重建。
- 候选快照保留实际归属增量、必要依赖、输入清单及删除／缺失证明，不把工作区总 diff 当归属范围，也不因节省空间遗漏必要输入。输入、摘要及用途均相同的不可变材料可复用；状态更新本身不需要再复制整个工作区。不同阶段的候选身份、清单和 before/after 引用仍各自准确，不因内容相同改写记录。
- 需要独立路径时优先采用文件系统支持的写时复制克隆，用可丢弃探针副本验证写入隔离，再核对目标内容与元数据；不修改证据本身来测试隔离，不支持时正常复制。不得用硬链接让不同候选、原件和备份互相可写，也不以新增符号链接替代证据文件。文件级内容寻址或克隆共享不改变逻辑路径和证据身份。

## 归档清理

用户明确授权清理范围后，在普通技能运行之外维护指定归档；不自动按时长、文件数或磁盘压力清除历史。开始前核实范围内 Run 全部终态、调用和小组全部闭合，原执行者、子 agent 和工具均已停止。活性未知、仍有恢复工作、并发修改或无法确认归属时保留现场；不为清理接管或停掉任务。当前容器的兼容锚点也属于引用核验范围。

### 分类与引用

- 核心记录持续保留：Task 定义与修订、Gate 和授权、Run 全部执行事实／checkpoint／预算／来源链、报告（含未登记报告）、切换清单及重定位索引，以及已有维护凭据、操作日志和恢复包。原文、版本、结果和摘要不改写，不用当前成功状态替换历史失败。
- 被引用证据及其必要依赖持续保留：候选与输入清单、前后基线、调用交付、审查／验证材料和必要日志。检查归档原件、备份、当前 Task/Run、Cohestra 引用、项目文档与既有归档，包含已压缩材料中的依赖；解析相对路径、绝对旧前缀、目录引用和兼容锚点，沿清单追踪依赖。仅用于文件盘点的登记不算语义引用，控制记录、候选清单和恢复材料中的真实依赖仍须保护。不能仅凭文件名搜索无结果认定可删除；引用解析不完整、动态路径或用途不明的材料保留。
- 只有同时确认无引用、无恢复／审计用途的临时提案才可移出原目录；文件后缀、名称和目录只是候选筛选条件。其他过程材料不顺带删除，核心记录即使零引用也不能移除。

### 压缩与去重

1. 先记录原件与备份的路径、内容 SHA-256、大小、模式和修改时间，以切换清单结合已核验的维护增量解释当前状态，核对已有恢复包；无法解释的差异先报告并停止相关操作，不把先前已压缩的散文件误判为丢失。保留旧清单和既有维护记录原字节，本次记录另存 `.yuzio/cadra-cleanup/<唯一标识>/`，记录范围、来源清单及维护记录摘要、分类依据、计划和逐项操作日志。
2. 无引用提案先转为可恢复压缩包，成员保留原容器相对路径及文件元数据。逐项核对成员集合、大小、模式、修改时间和内容摘要，并核验独立备份包后，复扫引用、确认执行与文件状态未变，再移除原件及备份中的对应散文件。必要 ACL／扩展属性无法保留时跳过；符号链接、特殊文件和异常成员不按普通提案处理。包与备份同盘时说明其不是异地备份。
3. 重复快照按实际内容摘要和元数据核实后，优先使用独立克隆共享数据块，保留每个原路径、内容、模式和修改时间，必要 ACL／扩展属性亦须保留。先在临时目标验证，再原子替换；不支持可靠克隆或元数据无法保留时跳过。被引用文件不得移入需要新解析器才能访问的压缩包，不改历史链接来掩盖缺失。
4. 操作前记计划与预期摘要，完成后追加结果。中断时依据日志和实际文件核实已完成项，复用已核验恢复包，不盲目重做删除。源文件或引用发生变化立即停止受影响操作；未验证的临时替代品不能替换原件。维护失败单独报告，不改 Run 状态、执行预算或历史结果。

### 验证与交付

- 对照原清单及维护增量，逐项核实剩余文件与恢复包成员，不丢核心记录或被引用证据。保留证据的路径、内容、模式、修改时间及兼容锚点；恢复说明列出压缩成员到原相对路径的映射，恢复先到独立空目录，不覆盖当前容器。
- 使用支持原协议的实际只读查询脚本核对历史 Task/Run 和结果；需要隔离时复制未改写的核心记录到临时容器查询，不改旧协议号或补新字段。核对历史链接可达及摘要，当前容器与范围外资料保持不变。无法读取的协议明确列出验证缺口，不声称历史查询已通过。
- 在归档说明追加维护入口，区分切换时清单与当前存储状态；容器副本、恢复包及维护索引共同构成清理后的恢复材料。既有历史正文和清单不回写。
- 清理前后测量同一卷可用空间，写盘同步后采样并记录时间、字节数及净变化；报告卷级测量可能包含后台分配／回收。逻辑重复字节、压缩前大小和 `du` 合计不等于实际释放空间。交付清理数量、保留与查询验证结果、恢复路径、测量结果及未处理项。
