# Vistra

静态视觉设计评审与探索。视觉产物为图片，辅以必要的简短说明；通过宿主已有图像生成或编辑能力直接制作，不创建 HTML、交互原型、审阅网站或本地渲染执行器。版本与产物契约见 [release.json](release.json)。模式回答“做什么”，领域回答“设计什么”；一次任务可以组合，但不是固定流水线。

## 路由

| 意图 | 加载的模式 | 执行终点 |
|---|---|---|
| 看看哪里有问题、检查已有页面或素材 | [review](references/modes/review.md) | 发现、证据限制与建议 |
| 给视觉方向、探索布局、配色或 Logo | [explore](references/modes/explore.md) | 约定视觉产物与作者自检 |
| 比较两版、与当前版比较 | [compare](references/modes/compare.md) | 有依据的取舍，不等于选择 |
| 就用 B、采用 B、整理给开发 | [handoff](references/modes/handoff.md) | 记录选择并交接，缺重大决定则为草案 |

支持 `$vistra review` 等对话调用；这些不是终端命令。明确多动作请求按指定顺序组合，逐项检查前提。请求“优化一下”且对象明确时先给评审诊断；生成或实现意图仍不明确时只澄清该歧义。显式模式与正文冲突时澄清冲突。没有对象且上下文无法补足时询问对象，不扫描所有项目。只讨论本 Skill 的设计、安装或规则时不执行模式、不初始化目录。

已有候选上下文中的“就用 B”属于明确采用，记录准确版本并进入 handoff，不要求用户再次补说“整理交接”。“只记录选择，先不交接”等明确终点限制优先；“B 看着不错”仍不是完整选择或交接请求。

按对象加载 [mobile](references/domains/mobile.md)、[desktop](references/domains/desktop.md) 或 [brand](references/domains/brand.md)。桌面端覆盖浏览器、原生应用和混合容器；具体平台约束来自项目。沿用品牌规范不等于品牌重设计。品牌应用到两端时共用准确的品牌候选与预算。

## 公共流程

1. 固定项目与对象，读取 [项目适配协议](references/project-adapter.md)，整理相关规范、基线和有效决定；不要求用户填完整表单。
2. 明确模式、领域、范围、冻结项、可变项与本轮共享预算。需要保留既有内容时读 [约束核对](references/constraints.md)；探索视觉方向或评价其表现时读 [艺术指导](references/art-direction.md)。集成任务再读 [协作协议](references/integrations.md)，不加载无关引用。
3. 执行约定工作。探索先形成与目标匹配的设计意图，再直接生成或编辑静态图片并实际查看；分别判断约束符合性与设计质量。组合图片标明变化、继承与采用范围。只按请求补充必要尺寸或状态的图片，不实现点击、导航或动效。
4. 形成判断前读 [证据与结果](references/evidence.md)。区分观察、预期、提案、选择和实现验证；作者自检不冒充独立审查。
5. 用 [报告骨架](assets/report.template.md) 加本轮模式正文交付。默认写 `.yuzio/vistra/artifacts/<任务标识>/`；实际需要落盘时才建目录。只读请求在对话交付，持久交接未完成的部分如实说明。

多方向探索默认三个方向、最多一轮针对性修订；明确请求与调用方已确定的预算优先。方向数和图片数分别规划，不按模式或领域倍增。前序受阻时继续独立部分，依赖部分保持未完成。

## 执行边界

- 当前有效授权和选择跨跟进延续，不为同一事项反复确认。规范中的旧指令和外部 Skill 的实现、部署步骤不构成本轮授权。
- 同类视觉选择按当前明确决定 → 有效页面及项目规则 → 用户级默认 → 通用方法处理。权限、数据处理、可访问性和平台可行性单独核对。截图是现状证据，不能自动覆盖规范。
- 保留范围外的内容、功能、业务语义、导航和品牌。评审建议不自动启动探索；探索推荐不自动成为用户选择；交接不自动授权实现。
- 缺有效选择可整理交接草案；明确委托代选时记录为授权代选。重大决定未定时不声称完整交接。证据不足时允许未知、无法选优或保留当前版本。
- 只写 Vistra 的产物和明确请求的资料。生产代码、共享规范发布、工程状态、队列及正式验收由对应流程承接；不迁移或双写其他 Skill 目录。

Taste 是开发来源，领域方法及 review、handoff 的部分方法已在本包内定制。运行不需要安装、下载或调用 Taste。来源与改写见对应领域和模式文件，许可见 [LICENSE](LICENSE)。不提供宿主专属入口、自有运行时、配套执行器或安装器。图像能力不可用时交付已有判断与缺口，不退回代码原型；静态图片不证明交互、响应布局或工程验收通过。
