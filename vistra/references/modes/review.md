# review · 评审

输入为可定位对象、范围和至少一种可检查材料。读对应领域；已有规范从有效入口获得，不把输入表单强加给用户。

1. 核实材料的对象、版本、状态和证据类别。按 [证据规则](../evidence.md) 限定结论。
2. 按下方清单选择本轮相关项，依次看事实与范围、内容完整性、任务与交互结构、层级与一致性、局部表现。保留既有内容时按 [约束核对](../constraints.md) 追溯要求与候选；评价表现时按 [艺术指导](../art-direction.md) 区分视觉目标和实际贡献。只检查有证据支持的项目。
3. 将确定问题、待核实项和可选建议分开；记录方式按交付用途确定。
4. 按下方“交付与停止”交付；没有发现问题也说明覆盖范围与影响结论的未检查项。

## 按范围检查

清单用于发现具体问题，不要求局部任务遍历所有维度。结合已加载领域和项目规则，记录实际覆盖、未检查与不适用项；同一发现不按维度重复计数。

| 维度 | 检查重点 |
|---|---|
| 内容与事实 | 必要字段、单位、日期、价格、文案与业务含义是否保留；名称、数字、评价和素材身份是否有依据；错误提示是否说明问题与可行下一步。示例与真实内容分开，不为画面自然随机化真实数据 |
| 任务与导航 | 当前对象、位置和主要动作是否明确；主次动作是否与任务一致；进入、返回、关闭和恢复路径是否连贯；图标导航是否有可理解的名称与选中状态。营销行动目标与产品工具效率分别判断 |
| 排版与可读性 | 标题、正文和辅助信息是否有稳定层级；行长、行距、换行、截断与数字对齐是否支持阅读；相关语言、长文本和放大文字是否损失内容。不因字体常见就要求更换，不套用统一标题行数 |
| 布局与密度 | 分组、对齐、内外间距和重复元素的基线是否表达内容关系；容器嵌套是否必要；主要操作是否被遮挡；内容扩张、窄视口或窗口缩放时如何重排。不能靠删字段、缩字或无条件加大留白解决问题 |
| 色彩与表面 | 颜色、强调、边界、层级和圆角是否沿用项目语义；状态是否只靠颜色区分；文字与背景是否可辨；图片、透明度和不同外观是否影响辨识。对比度测量需准确参数和检查记录，不能由截图观感判定通过 |
| 组件、图标与媒介 | 同类控件的含义、尺寸关系和状态是否一致；图标语义与风格是否沿用组件体系；图像裁切是否损害主体或素材身份；装饰是否挤占内容。卡片、分割线、系统图标或纯色背景本身不是问题 |
| 状态与操作反馈 | 按任务检查加载、空、错误、成功、禁用、处理中和选中状态；表单标签、校验、输入保留、重试与重复提交处理是否明确；按压、悬停或焦点反馈是否适合实际输入方式。没有相关状态材料时标未检查，不推断状态缺失 |
| 可访问性与动效 | 相关操作的可访问名称、键盘顺序、可见焦点和触控目标是否有依据；折叠或遮挡的内容是否仍可能获得焦点；动效是否服务状态关系，并有减少动态效果的策略。静态设计只检查表达或策略，实际可操作性及动效表现需运行证据 |
| 视觉概念与表现 | 按用途评价主视觉、构图、注意力顺序、字体与媒介配合及完成度。营销与品牌检查概念是否在画面成立；产品与阅读检查任务、内容关系。不以数量、可交互或检查通过推定审美达标 |

按本轮对象和材料选用以下细查，不新增全量必查清单：

- **动效回退**：涉及入场显现、滚动驱动、固定或叠放时，检查减少动态效果后的呈现。必要内容与操作应完整可达，不依赖动画完成才能出现；必要时恢复普通排列。仅有策略说明不证明实际回退可用。
- **网格与溢出**：区分有意留白和意外空洞，检查内容增减、窄视口及窗口缩放后的排列、阅读顺序和溢出。不能为了填满网格改变语义顺序，也不能用统一裁切隐藏内容或焦点被截断的问题。
- **标题排版**：出现碎裂换行或占用失衡时，联合检查文案长度、字体指标、字号、容器宽度及所在区域占比。调整后复查相关语言、窄视口和文字放大条件；指定宽度或行数不能单独证明问题解决。
- **条件性可读性**：文字或控件叠在图像、透明表面或动态背景上时，检查可能降低辨识度的裁切、背景和动效阶段。默认画面不能代表其他条件；缺少材料时标未检查，不要求为本轮范围外条件追加运行或出图。
- **标签用途**：涉及编号、徽章、胶囊标签或重复小标题时，检查是否帮助定位、理解或决策。无实际作用的装饰可建议简化；有导航、状态或识别作用的标签保留，不按名称或外形一律删除。

只有源码时评审结构、组件与策略，不说视觉已通过；概念图不证明真实触控、字体指标或无障碍。截图中无法辨认的内容先标未知，不从图像猜业务事实。单张默认态截图不能证明其他状态不存在；源码中的状态定义也不能证明实际呈现正确。需要运行验证的事项按 [证据边界](../evidence.md#证据能力) 交给工程流程。

建议优先处理事实与范围、核心任务和可访问性影响，再处理一致性与局部表现；严重度依证据规则和项目定义。区分影响任务的问题与可选风格建议，不按“先换字体”或“增加动效”的固定顺序改造，也不把发现清单转为自动修复指令。

结论分别说明约束符合性与设计质量。营销目标明显未达到时应给出具体视觉依据，不能仅以字段完整、无溢出或有多个方向判为良好；审美偏好与确定的规范违反分开。没有实际画面时只评审设计意图或策略，视觉质量保持未检查。

## 交付与停止

交付发现、位置与依据、影响、建议及证据限制；说明实际覆盖与必要未检查项，分别评价约束符合性与设计质量。正式报告的问题 ID、严重度和验证方法按 [证据规则](../evidence.md#问题与选择)；复审沿用旧 ID 与来源。

完成约定评审后结束，生成替代稿属于 explore，修改代码或关闭工程发现由相应流程承接。
