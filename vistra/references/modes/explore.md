# explore · 受约束探索

输入：目标、必要内容、允许变化范围。既有设计使用可用基线；新设计无需已有实现截图。品牌任务先识别新建、延展、局部调整或重塑。

## 形成可检验的方向

1. 按 [约束依据](../constraints.md) 区分必须保留、允许探索和尚不确定的内容，将关键来源与核对方式带入各候选；已有数据、组件和素材优先直接复用。
2. 解析共享预算：明确请求和调用方预算优先；独立多方向探索缺省三方向、最多一轮针对性修订。规划代表图和必要状态图，分别记录方向数、图片数、修订上限；进入其他模式或领域不重置。
3. 按 [艺术指导](../art-direction.md) 先形成设计意图与可见决策，再选表达。局部调整可用一句意图；营销和品牌方向需有主视觉与构图概念，不能只用对齐变化凑独立创意。各方向说明问题、收益与代价，保持同一必要内容、语言、状态、视口；差异条件明确列出。把“更紧凑”等目标转成可检查的关系或指标，注明依据；无法测量时保持未验证。
4. 使用宿主已有图像生成或编辑能力直接制作静态图片，参考图与原素材按实际角色提供。草案与制作共用预算，不强制先出草图，不创建 HTML/CSS、可运行原型、交互查看器或截图脚本。

| 本轮要判断什么 | 图片表达 | 能交付的证据 |
|---|---|---|
| 新的视觉气质、插画或开放概念 | 直接生成方向图 | 方向、内容关系和风格；不承诺精确几何 |
| 强主视觉，同时保留文字、Logo 或控件 | 提供准确内容和原素材，生成或编辑图片后逐项核对 | 可见的内容与身份关系；不能保证精确复刻的部分保持缺口 |
| 卡片高度、内边距、对齐、重叠或局部调整 | 基于现有图片编辑或生成局部对照图 | 可见关系和概念变化，不作为实际布局测量 |
| 不同尺寸、滚动位置或状态的视觉关系 | 只制作约定的代表尺寸或状态图 | 各图的可见状态，不证明响应布局、触发、恢复或操作有效 |

例如压缩卡片时同时观察卡片内边距与整个分组占高，新增分组标题可能抵消卡片节省；图中关系不等于原生布局单位。图像工具未准确执行几何修改时，在剩余预算内针对性修订，仍不满足则交付方向并明确精度缺口，不转为 HTML 或原生原型。更换图像工具不重置预算。

## 生成简报与自检

简报包含对象与目标、用途与领域、画布/视口、准确内容、冻结与可变项、候选决策、品牌/组件依据、状态、参考角色和不允许变化项。参考图分清现状、既有身份和风格灵感。向外部工具提交前核对实际内容与项目数据政策；无关敏感附件不随请求外发。

冻结文案时，字体样张和应用示例也复用已给文字；不要同时要求未指定文案的“标题/正文样本”，诱发额外产品承诺。工具新增的文案或元素视为偏差，不能因其看起来合理就纳入已确认内容。

工具返回后实际查看每个交付产物，先检查事实、字段、范围和结构，再检查层级、可读性、品牌与局部精度。记录乱码、图标失真、内容遗漏和工具能力限制。重新生成整页不能证明范围外像素未变；严格保留要求不能靠口头保证。

每个候选分别给出约束符合性与设计质量判断，遵循上述两个引用文件。修订后复查受影响项及相邻依赖，保留首稿偏差与最终结果，不用检查总数证明全部约束满足，也不因有三版就认定探索充分。

状态图保持同一数据与比较条件，只有请求需要时才补充；不为审阅增加方向切换器、筛选、弹窗或导航功能。图中按钮、选中态、详情和反馈仅表达设计意图，所有操作行为仍由后续工程验证。

多区域预览或沿用前轮内容时，按 [区域差异规则](../evidence.md#区域差异与采用范围) 标明本轮变化、沿用已选与暂作参照。整页位置被上方压缩带动，不等于下方内容也被重新设计。

一轮修订只针对已识别问题，不重新无界执行整套探索。预算耗尽时保留结果和缺口；不能为“更漂亮”隐藏错误、删字段、缩小文字或扩展功能。失败的图像不算完成的候选；尝试消耗也计入资源记录。

## 交付与停止

用 [explore 正文](../../assets/modes/explore.section.md) 交付实际候选、视觉意图、约束核对、设计判断、自检、修订与预算。核心目标已达到、未达到或尚未验证及依据分别说明，不把产物完成解释为目标达成；违规或偏弱方向如实保留，不强选最佳。需要图像而工具不可用时可交文字方向和生成简报，明确视觉交付未完成；不要把仅有描述写成已生成图片。

完成约定产物或预算耗尽即停止。自检与简要取舍属于本模式，不自动形成独立 review 或完整 compare，不代替用户选择或实现授权。
