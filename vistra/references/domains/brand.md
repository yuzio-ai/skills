# brand · 品牌视觉系统

覆盖 Logo、字标、配色、字体、图形/图像语言和应用规则。先判定新建、延展、局部调整或整体重塑。已有身份依据来自用户与项目，不由“是否附图”推断；缺少必要原素材时保留其身份约束，仅阻塞依赖该素材的交付。

## 设计方法

1. 确认本轮元素、受众、用途和品牌定位。已知事实与推导假设分开；局部配色任务不自动新建 Logo 或改变定位。
2. 从品牌行为、名称或产品意义提炼视觉概念。符号、字形、负形或几何只是可选方法；方向应解释意义与识别方式，不机械按行业配图。
3. 先检查单个元素，再检查系统关系：标志是否在不同大小可辨、色彩角色能否复用、字体层级是否适合语言与内容、图像风格是否支持同一身份。
4. 用与任务匹配的概念板、色板、字体样张或应用示例表达。没有固定 3×3、深色画布或整套品牌板要求；单项任务只交所需内容。

已有品牌素材按其真实角色作为图像参考或编辑输入，不能把用户标志当可自由改写的灵感图。灵感参考可提取节奏、密度、颜色关系与媒介方法，不冒用其 Logo、名称和独特资产。生成工具不能保证精确保留的素材，明确标出限制并保留原素材引用；不把生成图当作合格矢量母版，也不为补齐精度另做代码或渲染流水线。

品牌概念需要在主画面与实际载体中可见，不只在板外解释其哲学。按范围展示能检验识别与连续性的应用关系、尺度、图形、材质或图像语言；具体媒介不是必选清单。色值与字体参数可用于核对，但参数齐全不能代替表现力。概念画面与审阅说明分开呈现，避免用来源表、候选标签和长说明挤占主视觉。

已有身份延展可直接复用准确 Logo/Signature 与字体样张，再组合适合的应用素材；不因使用生成图就交出近似标志，也不因需要准确标志就预先排除材质和场景表达。各载体核对原稿、变体、净空与实际显示，不以同一文件哈希代替所有使用正确。

## 检查与交接

| 元素 | 方向评估 | 可执行交接 |
|---|---|---|
| Logo、字标 | 识别、平衡、变体一致性、不同背景表现 | 准确来源/修订、用途、变体、母版与待制作项；概念位图不是可编辑矢量 |
| 配色 | 主次、角色、组合、品牌连续性 | 明确值、色彩空间、语义用途和组合；从生成图采样的值标为提案，不能冒充既有 Token |
| 字体 | 字形气质、语言覆盖、层级与长度适配 | 可核实名称、字重、来源、可用性、必要回退；图片外观不能证明字体身份或许可 |
| 图形、图像语言 | 形状、构图、图标、摄影或插画是否一致 | 可复用规则、样例、素材来源、允许变化与限制 |
| 应用系统 | 同一候选在实际载体上的连贯性 | 本轮涉及载体、场景、保持一致部分及待验证项 |

可读性/对比度结论需要准确颜色与实际检查依据；视觉印象不能代替测量。Logo 可辨性测试或字体样张只覆盖实际尺寸和文字，不证明所有载体、语言都可用。未核实素材使用条件保持未知，不给法律结论。

## 跨领域应用

尚未选定品牌时，移动端、桌面端示例分别绑定同一候选的准确版本，不能混搭后再比较。选定后共用有效品牌依据；新增颜色、字体或应用方式标为提案，不在各端独立发明系统。

应用图用于表达身份与方向，不证明应用已实现。已存在的品牌规范作为界面输入即可，无需为读取它重启品牌设计。共享预算按方向和必要应用图规划，不按领域自动乘三。

领域生成简报补充：身份任务类型、冻结资产、已知定位/假设、概念意义、允许变化元素、颜色/字形意图、画布与应用载体。工具尺寸不支持时报告实际输出及影响，不承诺未生成的规格。
